## 📌 Overview  
An **AI-powered fraud detection system** for secure and fair online examinations.  
It prevents **cheating, identity theft, and malpractice** using:  
- 🔐 Facial recognition  
- ⌨️ Keystroke dynamics  
- 👀 Real-time monitoring (webcam + screen + movement)  

---

## 🎯 Key Features  
- **Biometric Authentication** – Face ID + typing patterns  
- **AI Monitoring** – Webcam, screen & behavior analysis  
- **Fraud Alerts** – Suspicious activities flagged instantly  
- **Scalable** – Supports universities, corporates & government exams  
- **Privacy First** – Secure data handling & compliance
